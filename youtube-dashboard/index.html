YouTube Studio のCSVを読み込む

インプレッション・CTR・視聴維持率など、YouTube Data API では取得できない非公開指標を扱えます。 ファイルはブラウザ内だけで処理され、サーバーへは送信されません。

CSVをここにドロップ、またはファイルを選択

YouTube Studio → アナリティクス → 詳細モード → エクスポート → カンマ区切り（.csv）

データ出典：YouTube Data API v3（公開指標）／ YouTube Studio エクスポート（CSVタブ）。 再生数の評価は、必ず /nensyuagent/ への送客（GA4）と接続して判断してください。
