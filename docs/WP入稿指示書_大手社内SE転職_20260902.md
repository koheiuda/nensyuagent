## 5. 計測設定（公開前に必須）

- 全CTA・関連記事リンクに `data-cta` / `data-cta-type` / `data-article="ote-shanaise"` を付与済み
- UTM：`utm_source=organic` `utm_medium=column` `utm_campaign=ote-shanai-se` `utm_content=cta1〜cta4／related_*／internal_*／faq_*`
- **属性の命名規約（2026-09-02改訂）**
  - `data-cta="cta1〜cta4"`：サービスへの本文CTA4本。**GTMのクリックトリガーはこの4本と `related_*` のみを対象にする**
  - `data-cta="related_sier／related_agent_change／related_reputation"`：記事末の関連記事リンク
  - `data-internal-link="internal_interview／internal_voice／faq_kyujin"`：記事内の回遊リンク。CTAクリック率の分母・分子に混ぜない
  - `data-internal-anchor="true"`：ページ内アンカー（`#four-types` `#naiseika`）。**計測対象外**（記事内スクロールを `click_cta` として発火させないこと）
- GA4は **パス `/nensyuagent/` で絞り込み**してレポートすること（本体と同一プロパティのため）
- GTMクリックトリガー → GA4カスタムイベント `click_cta`（cta_position／article／link_url）
- 追跡KPI：記事セッション／CTAクリック率（cta1〜cta4のみ）／LP到達数／CV（CV定義は未確定）／回遊リンククリック（internal_*・faq_* は別指標）

### 8,000字まで削らなかった理由

`記事制作プロンプト.md` の基本仕様（5,000〜8,000字）まで詰めるには、あと約2,700字の削減が必要になる。
散文はすでに圧縮済みのため、**残る削減余地はH2ブロック単位の削除しかない**。
具体的には「入社後3〜5年の働き方とキャリアパス」（約1,300字）の全削除が最有力だが、
これは**SERP上位3記事が扱っていない論点**であり（`data/STEP3_競合分析_社内SE転職大手_20260902.tsv` 参照）、
削ると本記事の優位性が1つ失われる。よって10,727字で止めている。

**8,000字への圧縮を優先する場合は、キャリアパスH2の削除を指示すること。**その場合h2は7本になり、ハウス標準（7〜9本）は維持される。
