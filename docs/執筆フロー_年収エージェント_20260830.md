## 1. KW選定（Day 1）

### 1-1. 候補出し
- Ahrefs Keywords Explorer：`転職エージェント` `年収 上げる` `キャリアアドバイザー` などのシード
- GSC（`/nensyuagent/` パス絞り）：掲載順位 5〜30位・表示回数のあるクエリ＝伸びしろ
- 年収チャンネルのコメント欄・動画タイトル＝一次needs

### 1-2. スコアリング（4軸／各5点・20点満点）
| 軸 | 見るもの | 満点の状態 |
|---|---|---|
| **CV接続性** | LPのUSP（担当者を選べる／独自求人／年収チャンネル）で解になるか | USPがそのまま「解決策」になる |
| **勝てるか** | KD、SERP上位のドメイン種別、独自性の余地 | 上位が汎用FAQばかりで一次情報の余地あり |
| **量** | 検索Vol＋サジェスト群の合計 | クラスタ合計で月1,000〜 |
| **安全性** | `/column/` とのカニバリ有無 | 本体側に同KW記事なし |

> **合格ライン：14点以上。CV接続性が2点以下のKWは、Volが大きくても書かない。**

### 1-3. カニバリチェック（必須・スキップ禁止）
1. `site:stock-sun.com/column/ 〈対象KW〉` で本体側の既存記事を確認
2. GSCで対象KWの現在の着地URLを確認（`/column/` が既に受けていないか）
3. 競合していたら → **本体側に統合を提案**するか、KWをずらす
4. 指名KW（「年収エージェント 評判」等）は `/column/annual-income-agent-reputation/` が1位のため**新規で狙わない**

## 2. 検索意図の解体（Day 1）

SERP1〜10位を実際に開き、次を表に落とす。

- **顕在ニーズ**：タイトルとH2で全社が触れている論点＝入れないと勝てない必須トピック
- **潜在ニーズ**：検索した人が「次に困ること」＝ここがCV導線の入口
- **コンテンツギャップ**：上位10本の誰も書いていない論点＝1位を取る差分
- **SERPタイプ**：how-to / 比較 / 定義 / 体験談。タイプを外すと順位は付かない

> この案件の鉄板パターン：**「顕在ニーズを最速で満たす → 潜在ニーズに橋渡し → USPが解になる」**
> 例）担当者を"変更する"方法（顕在）→ 変更しても次も合うとは限らない（潜在）→ 最初から"選べる"（USP）

## 3. 構成案作成（Day 2）

- **リードで結論を先出し**（3行以内）。転職顕在層は急いでいる
- **H2は7〜10本**、H2直下に必ず結論1文
- 上位10本の共通H2は**すべて内包**したうえで、独自H2を2本以上足す
- 表・チェックリスト・例文は**強調スニペット狙いで前半に**配置
- FAQセクションを設け、**FAQ構造化データ**を入稿指示に含める

### 見出しに入れる語
主KW＋「方法／例文／注意点／可能？」等の**共起語**。ただしH2への主KW詰め込みは3回まで。

---

## 4. 執筆（Day 3-4）

### 文体
- 敬体（です・ます）。1文60字以内。3〜4文で改行
- 一人称は使わない。断定できないことは断定しない
- スマホ幅で「文字の壁」を作らない（3段落ごとに表・箇条書き・囲み）

### 転職領域の必須ガード
- 「必ず年収が上がる」「100%」等の**断定的表現は禁止**
- 他社エージェントの**誹謗中傷はしない**（比較は事実ベースのみ）
- 法・制度に触れる場合は根拠（厚労省等）をリンク
- **数値は必ず出典と取得時点を併記**。未取得は本文に書かず、入稿指示書に「要取得」で残す

### E-E-A-T
- 年収チャンネル動画の埋め込み or 引用を**1本以上**
- 監修者／執筆者情報のブロックを用意（**誰を立てるかは要確認**）
- 一次情報（自社データ・キャリアアドバイザーの実務コメント）を最低1箇所

## 5. タイトル・メタ（CTR最大化）

| 要素 | ルール |
|---|---|
| タイトル | **全角32字前後**。主KWを左寄せ。`｜` で後半にベネフィット |
| 入れる要素 | ①主KW ②検索者の疑問への即答 ③感情ワード（角が立たない／損しない 等） |
| 入れない要素 | 数字の水増し、根拠のない「No.1」 |
| ディスクリプション | 全角**120字前後**。1文目で結論、2文目で独自価値（担当者を選べる） |
| 検証 | 公開2〜4週後にGSCでCTRを見て**タイトルABテスト**。実測CTRが同順位帯の中央値を下回れば書き換え |

## 6. CVR設計（この案件の肝）

### CTAは3点設置
| 位置 | 文脈 | 訴求 |
|---|---|---|
| ① リード直下 | まだ課題を認識した直後 | 軽い訴求（「担当者を選べるエージェントもあります」＋テキストリンク） |
| ② 記事中盤（解決策提示の直後） | 顕在ニーズを満たした直後＝納得度が最も高い | ボタンCTA。ここが本命 |
| ③ 記事末 | 読了層 | ボタンCTA＋FAQで残った不安を潰してから |

### 内部リンク
- 本記事 → **`/nensyuagent/`（LP）**：CTA3点＋本文中アンカー
- 本記事 → `/column/annual-income-agent-reputation/`（評判記事・1位）：「口コミを見たい人向け」で自然に
- `/column/annual-income-agent-reputation/` → 本記事：**本体側（`../stocksun`）への依頼が必要**

### 計測（公開前に必ず設定）
- CTAリンクに**UTM**を付与（`utm_source=organic&utm_medium=column&utm_campaign=〈記事スラッグ〉&utm_content=cta1|cta2|cta3`）
- GA4で**パス絞り込み**（`/nensyuagent/`）のうえ、CTAクリックをイベント計測
- 見るKPI：記事セッション / CTAクリック率 / LP到達 / CV（**CV定義は要確認**）
