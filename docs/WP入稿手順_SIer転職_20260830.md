# WordPress 入稿手順（手元のPCで実行）

対象記事：SIer転職は難しい？上流工程しかない経歴の伝え方と年収の上げ方
入稿先：https://test-nensyu-agent.kubooo.com（テスト環境）
ステータス：**下書き**

> **なぜ手元で実行するのか**
> Claude の実行環境は組織のegressポリシーで外部ホストへの接続が遮断されており
> （`gateway answered 403 to CONNECT`）、WordPressに到達できないため。
> ドメインを許可リストに追加してもらえれば、次回からはClaude側で入稿まで実行できます。

---

## 1. リポジトリを手元に取得

```bash
git clone https://github.com/koheiuda/nensyuagent.git
cd nensyuagent
git checkout claude/article-creation-branch-91emli
```

すでにcloneしてある場合：

```bash
cd nensyuagent
git fetch origin claude/article-creation-branch-91emli
git checkout claude/article-creation-branch-91emli
git pull
```

## 2. `.env` を作成

プロジェクトルートに `.env` を作ります。**`.gitignore` 済みなのでコミットされません。**

```
WP_URL=https://test-nensyu-agent.kubooo.com
WP_USER=nensyu_admin
WP_PASS=（WordPressのパスワード）
WP_BASIC_USER=check
WP_BASIC_PASS=（Basic認証のパスワード）
```

## 3. 接続確認

```bash
python3 tools/wp_draft.py --check
```

| 結果 | 意味 |
|---|---|
| `HTTP 405` | **正常。** GETを受け付けないだけで、投稿はできます |
| `HTTP 200` | 正常 |
| `HTTP 401` | Basic認証の失敗。`WP_BASIC_USER` / `WP_BASIC_PASS` を確認 |
| `HTTP 404` | XML-RPCが無効。`--mode rest` を試す（下記4-B） |

## 4. 入稿

### 4-A. 通常（XML-RPC）

```bash
python3 tools/wp_draft.py \
  --html "docs/articles/SIer転職_本文_20260830.html" \
  --title "SIer転職は難しい？上流工程しかない経歴の伝え方と年収の上げ方" \
  --slug sier-tenshoku \
  --excerpt "SIerからの転職先を、Web系事業会社・ITコンサル・SaaS・社内SEなど5タイプの年収レンジで比較。上流工程しか経験がない経歴を職務経歴書と面接でどう言語化すれば希望年収に届くのか、変換表と例文つきで解説します。" \
  --category コラム \
  --status draft
```

成功すると記事IDと編集URLが表示されます。

```
下書きを作成しました
  記事ID  : 123
  ステータス: draft
  編集URL : https://test-nensyu-agent.kubooo.com/wp-admin/post.php?post=123&action=edit
```

### 4-B. XML-RPCが無効な場合（REST API）

WordPress管理画面 > ユーザー > プロフィール で**アプリケーションパスワード**を発行し、
`.env` の `WP_PASS` をその値に差し替えてから：

```bash
python3 tools/wp_draft.py --mode rest --html ... --title ... --slug sier-tenshoku
```

※ `/wp-json/` がBasic認証の対象だとヘッダが競合します。その場合はサーバ側で
`/wp-json/` をBasic認証の除外にしてもらってください。

### 4-C. どちらも通らない場合

Googleドキュメントの「■ 以下、記事本文」以降をコピーして、
WordPressのブロックエディタに貼り付けてください。所要2分です。

- Googleドキュメント：https://docs.google.com/document/d/1ZlJ5WnzXtWNXKkBim5ORvJmW839Au4IM3483bLIjSOE/edit
- 本文HTML：`docs/articles/SIer転職_本文_20260830.html`

## 5. 入稿後にやること

- [ ] スラッグが `sier-tenshoku` になっているか
- [ ] カテゴリが「コラム」か
- [ ] メタディスクリプションを設定（SEOプラグイン欄）
- [ ] アイキャッチ画像を設定
- [ ] **スマホ幅で表9つの折返しを確認**（横スクロールが必要な表がないか）
- [ ] `noindex` が付いていないか
- [ ] **公開はしない。** 下書きのまま関係者レビューへ

公開前の確認事項は Googleドキュメントの「公開前チェック」欄を参照してください。

---

## 6. スクリプトの安全設計

- `--status` は `draft` と `pending` のみ。**`publish` は指定できません**
- 認証情報はコードに書かず `.env` から読み込みます
- `.env` は `.gitignore` 済み。本リポジトリは Public のため厳守してください
