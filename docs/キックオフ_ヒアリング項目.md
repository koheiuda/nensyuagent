# 年収エージェント キックオフ ヒアリング項目

作成日：2026-08-29
対象サービス：https://stock-sun.com/nensyuagent/

## 1. サービス理解
- サービスの提供価値（誰の、どんな課題を、どう解決するか）
- ターゲット（年齢／年収帯／職種／転職検討度合い）
- 料金・収益モデル（成功報酬／月額／その他）
- 競合サービスと、それに対する差別化ポイント
- NG訴求・言えない実績などのレギュレーション

## 2. 現状の数値
- サイトのセッション数（直近6〜12ヶ月）
- 流入チャネル内訳（自然検索 / 広告 / SNS / 直接 / 紹介）
- CV数とCV定義（フォーム送信 / 面談予約 / 電話 / LINE 等）
- CVR、面談化率、成約率、平均単価、LTV
- 広告出稿の有無・媒体・月予算・CPA

## 3. 計測環境・アカウント権限
- GA4（プロパティID／閲覧権限の付与可否）
- Google Search Console（プロパティ種別／権限）
- 広告アカウント（Google / Yahoo! / Meta 等）
- CRM・スプレッドシート等のリード管理方法
- タグマネージャの導入状況、CV計測タグの実装状況

## 4. 体制・ゴール
- KPI と目標値（期間・数値）
- 予算と月次工数
- レポーティング頻度・フォーマット・定例の有無
- 意思決定者と、施策実行の担当（デザイン／実装／原稿）
- 実装の反映フロー（CMS権限、修正の依頼先）

## 5. 既存アセット
- LP・記事・ホワイトペーパー等のコンテンツ一覧
- SNSアカウント（X / YouTube / TikTok / Instagram）
- メルマガ・LINE等のハウスリスト
- 過去に実施した施策と、その結果（うまくいった／いかなかった）

## 6. 初期に確認したい仮説
- `/nensyuagent/` への主要流入は「年収エージェント 評判」記事経由か？
  → 記事からサービスページへの内部リンク・CTAの導線を確認
- 指名検索（「年収エージェント」等）のボリュームと順位
- LPのファーストビュー・フォーム項目数がCVRのボトルネックになっていないか
