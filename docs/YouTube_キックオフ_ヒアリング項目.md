# 年収エージェント YouTube キックオフ ヒアリング項目

作成日：2026-08-30
対象チャンネル：`UCwrivK-bKlDu6ZJzC01GPBw`

> Web全体のヒアリングは `docs/キックオフ_ヒアリング項目.md` を参照。本書は YouTube 固有の論点のみ。

## 1. チャンネルの位置づけ
- YouTube を始めた目的（送客／認知／指名検索／採用 など）と、当初の想定との差
- 社内で YouTube の成果はどの数字で評価されているか
- 他チャネル（SEO・広告・SNS）との役割分担の考え方
- やめた企画・続かなかった企画と、その理由

## 2. 現状の運用体制
- 企画・台本・撮影・編集・投稿・分析の担当（内製／外注の別）
- 月あたりの投稿本数と、撮影のサイクル（まとめ撮りか都度か）
- 出演者は誰か、出演可能な頻度と拘束時間の上限
- 編集の外注先・単価感・納期（※単価の実数は本リポジトリに書かない）
- 投稿までのリードタイムと承認フロー

## 3. アカウント・権限
- YouTube アナリティクスの権限レベル（閲覧のみ／編集／オーナー）
- ブランドアカウントか個人アカウントか、オーナー権限の所在
- 概要欄・サムネ・タイトルを**こちらで直接編集できるか**（できない場合の依頼先と反映リードタイム）
- YouTube Data API / Analytics API 利用の可否（GCPプロジェクトの用意）
- 管理シート（`1lzxCOEann...`）の共有範囲と、各タブの用途
  - ※ 現在 Claude 側の接続アカウントからは開けないため、共有設定の確認が必要

## 4. コンテンツ
- 過去の動画のうち「手応えがあった」もの／「滑った」もの
- 話してはいけない内容・表現レギュレーション（実績、他社比較、報酬の表現など）
- 使える素材（実績データ、事例、顧客の声、社内ノウハウ）
- サムネイルの制作体制とトンマナのルール
- ショート動画の運用有無と、その方針

## 5. 送客導線
- 概要欄・固定コメント・終了画面の現在のリンク先
- UTM パラメータの付与状況（未付与なら、付与の実施可否）
- LP（`/nensyuagent/`）側に動画を埋め込んでいるか
- YouTube 経由の問い合わせを識別できているか（アンケート項目、計測、営業ヒアリング）

## 6. 目標
- YouTube 単体のKPIと目標値（期間つき）
- 予算（広告出稿・制作費の枠の有無）
- レポーティング頻度と、報告先（誰が読むか）
- いつまでに何が起きていれば「うまくいっている」と判断するか
