# 表現レギュレーション（転職・年収領域）

## 絶対に書かない

| NG | 理由 | 代替 |
|---|---|---|
| 「必ず年収が上がる」「100%転職できる」 | 効果の断定。景表法上の優良誤認リスク | 「年収アップを実現した事例があります」（事例の出典必須） |
| 「業界No.1」「最も優れた」 | 客観的根拠が必要 | 根拠がある場合のみ、出典と調査時点を併記 |
| 他社エージェントの否定・断定的な優劣評価 | 誹謗中傷リスク | 事実の言及のみ（「A社は公式サイトで変更方法を案内している」） |
| 出典のない統計・実績数値 | プロジェクト規約違反 | 本文に書かず、入稿指示書へ「要取得」で起票 |
| 個人が特定できる体験談 | 個人情報 | 属性のみに抽象化（「20代・IT営業の方」） |
| 「無料」「完全無料」の断定 | 料金仕様が未確認 | 仕様確認が取れるまで書かない |

## 数値の書き方

必ず **値＋時点＋出典** の3点セット。

- ○「年収チャンネル登録者28.2万人（2026年8月時点／自社調べ）」
- ×「年収チャンネル登録者約30万人」

取得できていない数値は、本文に書かず入稿指示書の公開前チェックリストへ。

## 法・制度に触れる場合

労働法・社会保険・税に言及する場合は、厚生労働省・国税庁など**一次情報へのリンク**を張る。
解釈が分かれる論点は「一般的には」と留保し、断定しない。

## 案件固有

- `/column/` 配下（StockSun本体SEOの管理領域）の記事は編集しない
- 指名KW「年収エージェント 評判」は既存記事が1位。新規で狙わない
- サービス仕様（料金・相談形式・担当者指名の可否）は**確認が取れた範囲でのみ**書く
