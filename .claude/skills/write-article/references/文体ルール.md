# 文体・表記ルール

## 文体
- 敬体（です・ます）
- 1文60字以内。40字前後が理想
- 3〜4文で改行。スマホ幅で「文字の壁」を作らない
- 一人称（私・当社）は使わない。サービス名は「年収エージェント」と表記
- 体言止めの多用禁止（1記事3回まで）

## リズム
- 3段落続いたら、表・箇条書き・囲みボックスのいずれかを挟む
- 「〜ます。〜ます。〜ます。」の3連続禁止。語尾を散らす

## 表記
| 対象 | 表記 |
|---|---|
| 数字 | 半角（2026年、5パターン） |
| 英数字と日本語の間 | スペースを入れない |
| 括弧 | 全角（　）。ただし例文プレースホルダは 〈　〉 |
| 箇条書きの文末 | 句点なし（体言・名詞句）／文の場合は句点あり |
| 強調 | `<strong>`。1つのH2ブロックに3箇所まで |

## 禁止表現
- 「〜と言えるでしょう」「〜ではないでしょうか」等の逃げ表現
- 「実は」「意外と」等の煽り接続詞
- 「様々な」「多くの」など、具体で置き換えられる曖昧語
- AIっぽい定型（「〜において重要な役割を果たします」「〜の観点から」）

## 読者の呼び方
「あなた」は使わない。主語を省略するか「〜したい方」とする。
