# ローカル／クラウド共通ワークスペース運用

このリポジトリでは GitHub をコードと文書の単一の正として扱う。

## 作業開始

1. `git status --short --branch` でブランチと未保存変更を確認する。
2. 未保存変更がある場合は、勝手に stash、reset、checkout、rebase、pull しない。
3. 作業対象と無関係な既存変更を編集・削除・commitしない。
4. 新しい作業は `feat/`、`fix/`、`chore/`、`docs/`、`claude/` の作業ブランチで行う。

## 作業終了

1. 変更内容とテスト結果を確認する。
2. 秘密情報、`.env`、認証情報、キャッシュ、生成物が追跡対象に入っていないことを確認する。
3. 作業ブランチへcommit・pushする。
4. `main` / `master` へ直接pushしない。PR経由で反映する。
5. 別環境へ引き継ぐときは、リポジトリ名、ブランチ名、最新commitを明示する。

## 環境間の引き継ぎ

- ローカルからクラウド：変更をcommit・pushしてから、クラウドで同じリポジトリとブランチを選ぶ。
- クラウドからローカル：クラウドの作業ブランチをpushしてから、ローカルでfetchし、同じブランチへ切り替える。
- 未commit・未pushのファイル、会話履歴、キャッシュ、実行中プロセスは同期されない。
